# NutriTracker Changelog

## [1.0.0] — 2026-04-08 (PWA — Open Source)
### Added
- Complete PWA nutrition tracker with AI-powered food photo analysis
- Multi-provider AI support: OpenAI, Anthropic, Google Gemini
- USDA FoodData Central + Nutritionix food database lookup
- AI Coach with persistent memory and anti-scam coaching rules
- Multi-conversation chat support
- Food photo analysis with confidence ranges and branded food detection
- Onboarding wizard with profile setup and macro calculation (Mifflin-St Jeor)
- Daily dashboard with calorie/macro tracking
- Meal history with bulk delete
- Weight/body fat tracking with Navy method calculation
- Daily nudge system (cached AI check-ins)
- Dietary preference tracking (allergies, restrictions, cuisines)
- Multi-user household support
- Service worker for offline caching (PWA)
- One-click install scripts (Windows + Mac/Linux)
